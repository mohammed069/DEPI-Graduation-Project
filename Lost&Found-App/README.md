# Lost and Found App

A web-based Lost and Found platform designed to help users report lost or found items and missing or found persons, making it easier to reconnect people with their belongings and families.

## Project Overview

The application provides a platform where users can:
- Report lost or found items.
- Report missing or found persons.
- Browse and search reports.
- View potential matches between lost and found reports.
- Communicate through an integrated messaging system.
- Receive notifications and updates.

## Main Features

- User Management
- Lost and Found Reports
- Items and Persons Categories
- Matching System
- Real-Time Communication
- Notifications
- User Verification

## Project Structure

- `Database/` - Contains SQL Server database scripts, constraints, indexes, and demo data.
