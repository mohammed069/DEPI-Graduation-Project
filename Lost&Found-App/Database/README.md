# Database

This folder contains the SQL Server database scripts for the Lost and Found App graduation project.

## Files Description

| File | Description |
|---|---|
| LostFound_DDL.sql | Creates the database tables, defines relationships and indexes. |
| Constraints.sql | Contains additional database constraints, including CHECK and FOREIGN KEY constraints. |
| Data.sql | Inserts sample data for testing and demonstration purposes. |

## Execution Order

1. Execute the DDL script.
2. Execute the Constraints script.
3. Execute the Demo Data script.

## Database Management System

Microsoft SQL Server
