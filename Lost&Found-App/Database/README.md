# Database

This folder contains the SQL Server database scripts for the Lost and Found App graduation project.

## Files Description

| File | Description |
|---|---|
| 01_LostFound_DDL.sql | Creates the database tables and defines the database structure. |
| 02_Constraints.sql | Defines CHECK, FOREIGN KEY, and other constraints. |
| 03_LostFound_Indexes.sql | Creates indexes to improve query performance. |
| 04_DemoData.sql | Inserts sample data for testing and demonstration. |

## Execution Order

1. Execute the DDL script.
2. Execute the Constraints script.
3. Execute the Indexes script.
4. Execute the Demo Data script.

## Database Management System

Microsoft SQL Server
